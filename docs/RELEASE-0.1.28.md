# Ferestre 0.1.28

This launcher update continues to use runtime 11.0.20261124.1.

- Turn on **Compact sidebar** in **Settings → Appearance** or the account menu for a 64-pixel rail. Game Pass and My Library show counts, and recent games use square artwork. Games started from this Ferestre window move to the top while they are active. A green bar beside the cover marks a running game.
- The **Jump back in** cards shrink slightly on hover and ease back when the pointer moves away. Ferestre follows the desktop's animation setting.
- The fullscreen toggle is at the far end of the header, and the notification button matches the rest of the sidebar.
- The controller focus ring stays visible around the first game in the compact sidebar.
- Ferestre bundles its own interface icons so the artwork stays consistent across desktop icon themes. The launcher icon uses two open panes in Ferestre green.
